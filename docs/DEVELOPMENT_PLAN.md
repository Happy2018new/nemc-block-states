## 目标

本库负责稳定、可审计的方块状态真值：输入版本化方块名和状态，输出规范化状态、合法的方向变换、伙伴关系及可供 renderer 消费的不可变快照。它不负责显示几何，也不负责主仓库的事务。

## API 与不变量

- 变换函数是纯函数，不能修改输入文档或读取渲染资源。
- 不合法或无法表示的变换返回明确原因，不能静默倒置、丢半组或修改伙伴关系。
- 同一最终状态快照同时供编辑器、完整投影和缺失投影使用；显示差异由 renderer 或主程序集成定位。
- manifest 必须包含 `game_version`、`block_palette_sha256`、生成器版本、来源提交和 schema 版本。
- 旧格式映射必须可解释；无法区分的历史歧义保留为未知，不猜测。

## 重构门槛

每期前半段做 1—2 个小批次重构，优先处理状态 API、来源 manifest、重复别名和版本检查。每三期做一次架构复盘；没有影响清单、回退方案和回归结果，不进行大规模迁移。重构不能通过删除断言、放宽阈值或重写历史来源来制造通过。
